# Levelle

📖 Automagically level reading books

Reference:

- [https://jsfiddle.net/f5L38emf/]

## Flow

- Uses device camera to take a picture of a passage
- Parses the text from the image
- Runs the text through reading-level calculations
- Determines the approximate reading level of the text

## Stories

- As a teacher, I want to be able to quickly level a passage for my classroom library
- As a parent, I want to determine the reading level of a library book for my child

## Architecture

- No external services: everything needs to run on the device (primarily mobile web)
